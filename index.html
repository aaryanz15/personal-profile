03 / 05

Secured

2026 · Solo

What you see are we still on for 7? yes, the usual place safety number matches ✓ sending the file now What the server stores AES-256-GCM · ECDH P-256
Problem
Private conversations usually trust the server with plaintext.
Solution
An invite-only two-person chat encrypted in the browser (ECDH P-256, HKDF, AES-256-GCM). The server stores only ciphertext, calls go peer-to-peer over WebRTC, and messages vanish 24 h after they're read.
My contribution
All of it, solo: design, crypto, React client, FastAPI backend with Argon2id, and 68 pytest tests.
Stack
React 19 · Web Crypto · WebRTC · WebSockets · FastAPI · SQLAlchemy · PostgreSQL · pytest

Tripmate

2026 · Team

Problem
Travellers can't read the signs, menus and landmarks around them, and have no local to ask.
Solution

The homepage redesign in Next.js + Motion: scroll-linked cinematic stages, a parallax hero, and AR and itinerary previews.
